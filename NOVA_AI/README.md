
# 🤖 Ollama AI Chatbot

A ChatGPT-style AI chatbot built using Streamlit and Ollama.

## Technologies

- Python
- Streamlit
- Ollama
- Llama 3.2

## Features

- ChatGPT-style interface
- Local LLM
- Chat history
- New Chat
- Streaming responses
- No OpenAI API
- No paid API
- No API key required

## Architecture

Google Colab → Ollama → Llama 3.2 → Streamlit
